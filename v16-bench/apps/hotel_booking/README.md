# Hotel Booking Module for ERPNext v16

A comprehensive hotel booking module for ERPNext version 16.

## Features
- Hotel management (multiple properties)
- Room Types (Single, Double, Suite, etc.)
- Room inventory with status tracking
- Guest management
- Booking with check-in/check-out
- Booking Items (multiple rooms per booking)
- Availability checking
- Billing integration

## Doctypes
- **Hotel** — Hotel property master
- **Room Type** — Room categories with pricing
- **Room** — Individual room inventory
- **Guest** — Guest records
- **Booking** — Reservation master
- **Booking Room** — Child table for multi-room bookings
